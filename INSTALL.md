# Швидкий старт

1. Розпакуйте архів.
2. Відкрийте папку `ContactsApp` у VS Code.
3. Виконайте `npm install`.
4. Виконайте `npx expo install --fix`, щоб синхронізувати версії Expo-пакетів із SDK.
5. Виконайте `npx expo start`.

Якщо TypeScript або Expo вкаже на несумісність версій після встановлення, спершу повторіть `npx expo install --fix`.
